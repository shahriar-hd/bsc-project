# Implementation Plan: Training Code Optimization & Bug Fixes for 4GB VRAM

This plan addresses all discovered bugs, optimizes memory and computational throughput for the RTX 3050 (4GB VRAM), corrects architectural and scheduling issues, and prepares the training pipeline for headless execution via tmux.

## User Review Required

> [!IMPORTANT]
> - **Batch Size & Frame Count**: To ensure zero-OOM on the 4GB RTX 3050 GPU (where the desktop UI already consumes ~1.3GB), we set `batch_size = 4`, `grad_accum_steps = 4` (effective batch size = 16), and `num_frames = 8` (or 16).
> - **DataLoader Workers**: Set `num_workers = 2` to prevent host RAM inflation and CPU thread contention on the laptop i7-11800H.
> - **Single GPU**: Explicitly configured for single GPU (`use_data_parallel = False`, `use_ddp = False`) to eliminate unnecessary DataParallel overhead.

## Summary of Fixes and Optimizations

1. **Bug Fix 1 (Critical - PCGrad Zero Update)**: Fix `train.py` so that when `use_pcgrad = True`, the projected gradients are properly accumulated, scaled/clipped, and `optimizer.step()` is called on accumulation boundaries.
2. **Bug Fix 2 (Critical - Validation Temporal Loss)**: Fix `temporal_consistency_loss` call in `validate()` to pass ground-truth labels `tmp_lbl` instead of prediction logits `tmp_logit`.
3. **Bug Fix 3 (Critical - CSV File Names)**: Update `PathConfig` in `config.py` to match the actual CSV filenames generated by preprocessing (`ff_train.csv`, `siw_train.csv`, etc. instead of `FaceForensics++_train.csv`).
4. **Bug Fix 4 (GradNorm Scheduling & Memory)**: Enforce `gradnorm_interval = 10` so second-order autograd passes only occur every 10 steps, freeing computation graphs on all other steps.
5. **Architectural Optimization (TSM Integration)**: Correctly apply Temporal Shift Module (TSM) on intermediate feature stages (inside MBConv blocks where channels are 32/56/120) rather than corrupting the raw 3-channel RGB input pixels.
6. **Memory & Throughput Optimization**:
   - Enable `torch.backends.cudnn.benchmark = True` for fast convolution kernel selection.
   - Pinned memory transfer with `non_blocking=True`.
   - `optimizer.zero_grad(set_to_none=True)` to deallocate gradient tensors immediately instead of filling them with zeros.
   - Periodic cache cleanup and garbage collection.
